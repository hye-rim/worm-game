# 지렁이 게임 🐛

먹이를 먹고 길어지는 스네이크 클래식입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

## 조작
- 키보드: 방향키 또는 `WASD`, `P` 로 잠깐 멈춤(시작은 방향키/`Space`).
- 폰: 화면을 밀거나 버튼을 눌러 방향 바꾸기, 탭하면 시작.

## 규칙
- 먹이를 먹으면 몸이 길어지고 점수가 오릅니다. 벽이나 내 몸에 부딪히면 끝.
- 최고 점수는 `wormBest`.

## 🎁 아이템 모드 (위쪽 버튼으로 고름)
기본 규칙은 그대로이고, 돌이 있는 판에 **아이템**이 가끔 나옵니다. 모드는 시작 전·게임 오버 뒤에만 바꿀 수 있고(게임 중에는 잠김), 마지막에 고른 모드가 기억됩니다. **기록은 기본 모드와 따로** 저장됩니다(`wormItemBest`). 기본 모드 기록(`wormBest`)은 로비에 보이는 그대로입니다.
- **돌 판 4종** (시작할 때 무작위): 빈 들판 · 돌 정원(흩어진 돌 10개) · 모서리 담(네 모서리 ㄱ자) · 미로 담(가로 담 두 줄). 처음 서 있는 가운데 줄과 앞길은 늘 비어 있고, 돌이 아닌 모든 칸이 서로 이어져 있습니다(시험).
- **아이템**: 사과를 3~5개 먹을 때마다 하나가 나오고 약 9초(70걸음) 뒤 사라집니다(고리가 줄어들다 깜빡임). 사과보다 먼저 먹어도 됩니다.
  - ⭐ **황금 사과**(45%): +5점, 몸도 한 마디 길어집니다.
  - 🐌 **느린 걸음**(30%): 40걸음 동안 걸음이 1.6배 느려집니다. +1점.
  - 🛡 **보호막**(25%): 35걸음 동안 **벽은 반대편으로 나오고, 내 몸과 돌을 지나갑니다**. +1점. 끝나기 전에 깜빡입니다. 끝난 뒤에는 다시 벽·몸·돌에 부딪히면 끝.
- 남은 효과 시간은 화면 왼쪽 위 배지(🛡 6초)로 보입니다. 걸음 속도는 **먹은 개수**로만 빨라져서, 황금 사과의 보너스 점수 때문에 갑자기 빨라지지는 않습니다.

### 균형을 어떻게 맞췄나
- 최단 길을 찾는 봇(실수 확률 0%·5%)을 30판씩 돌렸습니다. 모든 판이 결국 끝나고(갇혀서), 점수 중앙값은 기본 60 vs 아이템 61~70(실수 5%에서는 18 vs 11~22). **미로 담이 가장 어렵고** 나머지는 기본과 비슷합니다. 봇은 황금 사과만 노려서 보호막·느린 걸음은 거의 못 먹으니, 이 두 아이템의 체감은 측정하지 못했습니다.
- **사람이 하는 체감 재미·난이도와 폰 터치 감각은 측정하지 못했습니다.**

## 구조
- `index.html` 화면·입력, `logic.js` 규칙(돌 판 `MAPS`, 아이템 `spawnItem`·`takeItem`, `speedOf` 포함).
- 규칙은 DOM 없는 `logic.js`, 시험은 `node --test` (`test/logic.test.js`, 아이템 시험 10개 포함).
